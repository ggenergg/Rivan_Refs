## LISP

- EID : Endpoint Identifier 
- Map Resolver/Server
- RLOC : Network where Sites Communicates via LISP 
- ITR : Points IP address for Map Resolver   ! ITR + ETR = XTR
- ETR : Register EID to Map Server
- ITR & ETR : If a packet has a source IP from it's database-mapping, it acts as an ITR


| EID              | RLOC       | 
| ---              | ---        |
| 10.11.11.96  /27 | 208.8.8.11 |
| 10.21.21.208 /28 | 208.8.8.12 |
| 10.0.0.0     /30 | 208.8.8.13 |


__Map Resolver /Map Server__
~~~
!@UTM-US / HQ
conf t
 router lisp 1
  ipv4 map-server
  ipv4 map-resolver
 !
  site PH
   eid-prefix 10.11.11.96/27
   authentication-key C1sc0123
 !
  site JP
   eid-prefix 10.21.21.208/28
   authentication-key C1sc0123
 !
  locator-table default
  end
show lisp 1 site summary
sh lisp 1 site rloc members
~~~


__XTR__
~~~
!@UTM-PH 
conf t
 router lisp 1
  ipv4 itr
  ipv4 etr
  ipv4 itr map-resolver 208.8.8.13
  ipv4 etr map-server 208.8.8.13 key C1sc0123
  locator-table default
  locator-set RLOCS
   ipv4-interface g1 priority 100 weight 100
  !
  eid-table default instance 0
   database-mapping 10.11.11.96/27 locator-set RLOCS
  end
sh ip lisp 1 map-cache 
show lisp 1 database
~~~

# Quality of Service
*Why need QoS? Periodic Congestion*


1. __Best Effort__ - Not Strict. (FiFo) First come first serve traffic management.

<br>

2. __DiffServ__ - Less Strict. Bandwidth Guarantee for each application and share bandwidth with other apps depending on when they need it.

<br>

3. __IntServ__ - Strict. Bandwidth Guarantee for each app but does not share with other apps even if a certain app is not using bandwidth.

~~~

  permit ip host 192.168.103.102 host 1.1.1.1

  permit ip host 192.168.103.103 host 8.8.4.4
 !

  match access-group name ACL-8

  match access-group name ACL-1
 class-map match-any CM-84
  match access-group name ACL-84
 !
 policy-map PM1
  class CM-8
   set dscp AF21
  class CM-1
   set dscp CS3
  class CM-84
   set dscp 41
  class class-default

  match ipv4 destination address

  match transport destination-port

  match ipv4 version
  match interface input
  match interface output
  collect counter bytes
  collect counter packets
  collect transport tcp flags
  collect flow direction
  collect timestamp absolute first
  collect timestamp absolute last
  collect ipv4 tos

  collect routing destination as

### Site-to-Site
Configure Site-to-Site VPN for Cust-B 
- Authentication must be via PSK
- Password: VPN-Bkey
- Use a Crypto Map

> VPN IKEv1 using Crypto Map            [ HQ-Z > B-B1 ]
> IKEv1 IPSec Profile (GRE over IPSec)  [ HQ-Z > B-B1 ]
> VPN IKEv2 via VTI (GRE over IPSec)    [ HQ-Z > A-B2 ]


IKE Phase 1 – Routers exchange keys securely (like a private handshake).
IKE Phase 2 – They agree on how to encrypt real data (the “data tunnel”).
Crypto Map – Tells router which traffic to encrypt (based on ACL).
IPsec SA (Security Association) – The live, active tunnel where packets get encrypted.
Encapsulation – Each packet from LAN A → LAN B gets wrapped (encrypted) before it leaves the WAN.


Determine the ff values:
                         SITE A (HQ-Z)                 SITE B (B-B1)
Phase 1
  PSK:
  Peer:
  Encryption:
  Integrity:
  DH Group:

Phase 2
  ESP-Encryption:
  ESP-Hash:
